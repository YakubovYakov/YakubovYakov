## Главный проект: [gkb-24.ru](https://gkb-24.ru)

Публичный сайт московской ГКБ № 24: страницы врачей и отделений, онлайн-запись, админ-панель с правами по разделам. Код закрытый, поэтому коротко о том, что внутри (подробнее в [gkb-24-case](https://github.com/YakubovYakov/gkb-24-case)):

- две версии сайта из одной кодовой базы, маршрутизация по поддомену
- серверный рендеринг и SEO: JSON-LD, карта сайта по хосту, скрипт, который обходит все страницы и проверяет канонические адреса
- 900+ коммитов, 110 файлов тестов, CI на GitHub Actions
- деплой с автоматическим откатом, если сборка или запуск не прошли
- журнал действий администраторов, лимиты запросов, IP хранится только в виде хеша
